02 / Independent AI engineering

The workflow around the model is engineering work.

I design development workflows for my personal software projects. I build these projects with AI assistance and own the design decisions, review and tradeoffs.

Agent development workflow

Separate implementation from review; make retries accountable.

My agent development pipeline coordinates work across repositories. It uses plans and dependency contracts, separate implementation and review steps, bounded retries, saved state and run journals. Reviewer feedback feeds the next attempt.

  1. 1. PlanScope and dependency contracts
  2. 2. ImplementChanges and verification
  3. 3. ReviewAccept, retry or stop

I track usage and cost by phase and set minimum model capabilities for each role. After an infrastructure failure during review, a review-only retry avoids repeating implementation. A test harness produces compact results with detail available when needed.

Verification: local tests with mocked agents exercise coordination and retry behavior. These checks do not measure live model quality or establish production reliability.

Conversational backend

Handle the stream, the failure and the cancellation.

My independent TypeScript/Node.js conversational backend uses the OpenAI and Anthropic SDKs directly. It handles streaming and non-streaming requests, bounded SDK retries, configured provider fallback before output begins, and cancellation.

Verification: focused local tests with SDK fixtures cover API, fallback and context behavior. This is local integration evidence, not a live model evaluation or a production deployment.
